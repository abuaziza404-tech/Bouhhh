# أحمد أبو عزيزه الرشيدي

**Ahmed Abuaziza Al-Rashidi**

شاعر نبطي وباحث سوداني من شرق السودان، من أبناء الرشايدة. يكتب القصيدة بوصفها سجلًا للمكان والوجدان، ويصل الموروث النبطي بتجربة معاصرة تتجه إلى القارئ العربي.

## القاش والتاكة

ديوان شعر نبطي يضم **47 قصيدة** و**478 بيتًا** في **ثمانية أقسام**.

> «أنا وانت تربطنا علاقة غلا وهيام  
> فريده مثل علاقة القاش والتاكة»

مقتطف من قصيدة «القاش والتاكة» لأحمد أبو عزيزه الرشيدي.
